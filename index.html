Draft tersimpan otomatis di browser ini
Kertas cetak: A4 lanskap — bagan otomatis dipecah per halaman dengan konektor segilima penyambung halaman.
Panduan singkat
  1. Klik SOP Baru. Isi tab Identitas SOP (nomor bisa dibuat otomatis).
  2. Di tab Bagan Alir, atur kolom pelaksana lalu tambahkan langkah berurutan: Mulai → Proses/Keputusan/Dokumen → Selesai.
  3. Untuk Keputusan, pilih langkah tujuan jika hasilnya "Tidak". Garis konektor digambar otomatis.
  4. Semua perubahan tersimpan otomatis di browser. Gunakan Simpan File / Backup Semua untuk menyimpan ke flashdisk atau memindahkan ke komputer lain.
  5. Cetak / Simpan PDF → pilih printer "Save as PDF / Microsoft Print to PDF", ukuran A4, orientasi lanskap.
